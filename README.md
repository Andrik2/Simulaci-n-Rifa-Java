# Simulación-Rifa-Java

## Descripción
Simulación de rifas digitales hecho en Java que genera, asigna y selecciona boletos de forma dinámica aplicando concurrencia y paralelismo.

## Tecnologías
- Java
- Programación Orientada a Objetos
- Programación Concurrente y Paralela

## Funcionalidades
- Generación de boletos (en cantidad)
- Visualización de boletos ocupados y no ocupados
- Apartado de boletos por nombre
- Selección de un solo ganador de manera aleatoria
- Métricas con tiempos de ejecución en las distintas funcionalidades.

## Cómo ejecutar
1. Abrir el proyecto en NetBeans
2. Ejecutar la clase principal
